# Weather forecast data

`//GRID` retrieves forecasts from the selected provider at runtime. Weather
forecast data licenses and API terms are separate from the `//GRID` source
license (GPL-2.0-only).

## Open-Meteo

- Source: [Open-Meteo](https://open-meteo.com/).
- Data license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- [Attribution policy](https://open-meteo.com/en/licence): link to the source
  alongside displayed weather data.
- [API terms](https://open-meteo.com/en/terms): the free API is for
  non-commercial use only.

## MET Norway

- Source: [Norwegian Meteorological Institute (MET Norway)](https://www.met.no/).
- Data licenses: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
  and [NLOD 2.0](https://data.norge.no/nlod/en/2.0).
- [Licensing policy](https://api.met.no/doc/License) and
  [API terms](https://api.met.no/doc/TermsOfService).

## Adaptations

`//GRID` rounds temperatures, maps provider condition codes to its display
conditions, and selects up to 12 hourly forecast points. Neither provider
endorses `//GRID`.
